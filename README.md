# COMP4033 计算机图形学 - 小组项目

==========================================

* 
**项目名称：** 包含 6 种渲染特效的 3D 交互式场景 


* 
**开发引擎：** OpenGL 3.3 (GLUT + GLEW + GLM) 



---

## 如何编译与运行

1. 从 ispace 下载最新的 `updatedAssign0.zip` 并解压（例如解压到一个名为 "lightdemo" 的文件夹中） 。


2. 将以下内容复制或克隆到该文件夹中 ：


* 
`Assign0\`（源码文件） 


* 
`Assign0.sln`（解决方案文件） 


* 
`Debug\`（预捆绑的 DLL 动态链接库和资源文件） 




3. 使用 Visual Studio 打开 `Assign0.sln`（推荐使用 VS 2019 或 2022） 。


4. 选择配置：Debug | Win32 。


5. 点击菜单栏 **生成 > 生成解决方案**（或使用快捷键 `Ctrl+Shift+B`） 。


6. 生成的可执行文件将出现在：`Debug\Assign0.exe` 。


7. 双击 `Debug\Assign0.exe` 即可运行 。


* 
*注意：必须在 `Debug\` 文件夹内运行该 `.exe` 文件（因为纹理和着色器是相对于当前工作目录加载的）* 。





### 常见错误排查：

* 
**如果编译失败并提示 "cannot open include file: GL/glew.h"：** 


* 在 VS 中，前往：**项目 > 属性 > C/C++ > 常规 > 附加包含目录** 。


* 将其指向包含 `GL\` 子目录的文件夹（例如 `glew-x.x\include`） 。




* 
**如果编译失败并提示 "cannot open file glew32s.lib"：** 


* 前往：**项目 > 属性 > 链接器 > 常规 > 附加库目录** 。


* 将其指向包含 `glew32s.lib` 的文件夹 。

## 已实现的特效（共 8 种，远超 6 种特效的加分门槛）

1. 
**镜面反射 (Specular Reflections) —— [对应要求 #5]** 


* 所有表面（房间、角色、球体）均采用 Blinn-Phong 光照模型 。


* 设有 3 个点光源：每个房间各一个 + 走廊一个 。


* 房间内为暖色调光照，走廊内为白光 。




2. 
**相机可见的光源 (Light Sources Visible to Camera) —— [对应要求 #7]** 


* 3 个点光源在天花板高度处均有一个微型、自发光的球体；球体的亮度与光源颜色同步脉动 。




3. 
**动画对象 - 弹跳的球 (Animated Object - Bouncing Ball) —— [对应要求 #2]** 


* 一个橙红色的球体在 1 号房间内弹跳，并在所有六个表面（地板、天花板、四面墙壁）上进行反弹 。




4. 
**透明对象 - 玻璃面板 (Transparent Objects - Glass Panels) —— [对应要求 #4]** 


* 两块带蓝调的玻璃面板立在走廊中 。


* 采用 Alpha 混合（Alpha-blended）并带有镜面高光；在所有不透明几何体渲染完成后进行渲染 。




5. 
**粒子系统 - 火焰 (Particle System - Fire) —— [对应要求 #3]** 


* 2 号房间内（靠近南墙）的火炬火焰特效 。


* 粒子使用 `GL_POINTS` 并带有叠加混合（additive blending）；随着粒子生命周期消耗，颜色从明亮的橙色渐变为透明 。




6. 
**阴影贴图 (Shadow Mapping) —— [对应要求 #6]** 


* 在 1 号房间上方使用正交光源，生成 2048x2048 分辨率的 PCF（3x3 滤波核）阴影贴图 。


* 弹跳的球和行走的角色的地板上会投射出软阴影。在 1 号房间低头看地板时视觉效果最佳 。




7. 
**动态纹理 (Dynamic Textures) —— [对应要求 #1]** 


* 地板的 UV 坐标随时间连续滚动，营造出表面图案缓慢漂移的视觉效果 。


* 1 号房间和 2 号房间的暖色光源呈正弦脉动（亮度变化约为 $\pm10\%$），自发光球体同步脉动 。




8. 
**凹凸贴图 (Bump Mapping) —— [对应要求 #8]** 


* 对所有垂直墙面应用了程序化凹凸贴图（Procedural bump mapping） 。


* 通过 `dFdx`/`dFdy` 导数计算出逐片元的切线空间正交基（tangent frame）；利用基于正弦的高度场来扰动表面法线，从而在镜面光照下为墙面纹理增加可见的微观细节 。

## 场景描述

* 
**1 号房间（左侧）：** 弹跳的球、Phong 光照、地板阴影、桌子 + 椅子 。


* 
**走廊（中间）：** 两块玻璃面板、可见的光源球体 。


* 
**2 号房间（right）：** 行走角色的终点、火焰火炬、桌子 + 椅子 。



> 💡 **角色动态：** 角色会自动通过走廊在 1 号房间和 2 号房间之间往返行走，并持续循环 。
